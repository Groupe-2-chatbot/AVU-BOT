# 🎓 AVU-BOT — Assistant de Vie Universitaire

AVU-BOT est un agent conversationnel développé dans le cadre d'un projet académique à **IRGIB Africa**.

Son objectif est d'accompagner les étudiants en répondant à leurs questions concernant la vie universitaire.

## ✨ Fonctionnalités

- Interface web moderne développée avec Streamlit.
- Assistance en français et en anglais.
- Réponses aux questions fréquentes des étudiants.
- Reconnaissance de plusieurs intentions.
- Modèle de Machine Learning basé sur TF-IDF et Logistic Regression.

## 📚 Domaines couverts

- Salutations et remerciements
- Localisation de l'université
- Tenue vestimentaire
- Contact avec le personnel
- Transport
- Inscriptions
- Bibliothèque
- Wi-Fi
- Parking
- Cantine

## 🛠️ Technologies utilisées

- Python
- Streamlit
- Scikit-learn
- TF-IDF
- Logistic Regression

## 🚀 Installation et lancement

**1. Cloner le dépôt**

```bash
git clone URL_DU_DEPOT
```

**2. Accéder au dossier**

```bash
cd AVU-BOT
```

**3. Créer un environnement virtuel**

```bash
python3 -m venv .venv
```

**4. Activer l'environnement**

```bash
source .venv/bin/activate
```

**5. Installer les dépendances**

```bash
pip install -r requirements.txt
```

**6. Lancer l'application**

```bash
streamlit run app.py
```
